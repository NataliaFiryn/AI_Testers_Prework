# Commit messages

Use Conventional Commits for every commit:

`<type>(optional-scope): <short description>`

Use a lowercase type such as `feat`, `fix`, `test`, `docs`, `refactor`, `chore`, or `ci`. Write the description in the imperative mood, keep it concise, and do not end it with a period.

Example: `test(smoke): add main page navigation checks`

# Testing

Use the Playwright Test framework for automated tests. Review `playwright.config.ts` when creating tests to ensure they follow the project's configured settings and conventions.
